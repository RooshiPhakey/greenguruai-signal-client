# Contributing

This repository is intentionally small.

Useful contributions include:

- fixes to the Python or JavaScript examples;
- clearer examples for supported API filters;
- documentation corrections;
- examples that preserve GreenGuruAI attribution and original-source links.

Please keep new examples dependency-light unless there is a clear reason otherwise.

For API behaviour and reuse rules, see:
https://www.greenguruai.com/developers
